# MMM-LibraryMonitor Wiki

MMM-LibraryMonitor shows borrowed items, due dates, reservations, and account summaries from a supported OPAC account.

## Screenshot

![MMM-LibraryMonitor](../preview.png)

Use this wiki if you want to:

- install the module cleanly
- start with one account first
- switch later to multiple accounts
- configure due-date and account-summary display options
- troubleshoot login or parsing issues

## Scope

The current module scope focuses on account overviews:

- borrowed media and due dates
- reservations from the account overview
- no media search
- no profile management
- no renewal workflow
